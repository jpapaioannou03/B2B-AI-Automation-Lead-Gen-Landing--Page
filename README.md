# B2B AI Automation Lead Gen Landing Page

A modern landing page for a B2B AI Automation and Lead Generation service built with React, Vite, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework:** React 18
- **Tooling:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

### Prerequisites

- Node.js (v18 or newer recommended, installed v24.20.0 LTS)
- npm

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Type Checking & Linting

```bash
npm run typecheck
npm run lint
```
